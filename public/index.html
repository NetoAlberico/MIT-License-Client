Gere e gerencie os códigos de acesso das assinaturas dos seus clientes. O mesmo token funciona em qualquer app "MIT" que tenha o módulo mit-license.js instalado, desde que a chave secreta abaixo seja igual nos dois lugares.

Chave secreta

Essa chave precisa ser exatamente igual à CONFIG.SECRET dentro do arquivo mit-license.js de cada app. Troque o valor padrão por algo só seu e guarde em local seguro — quem tiver a chave consegue gerar tokens válidos.

Limite de dispositivos

Preencha só se for usar o limite de "Dispositivos permitidos" ao gerar tokens — sem isso, o campo existe mas não é aplicado de verdade. Veja como publicar o license-server no INTEGRACAO-LICENCA.md.

Criar conta de usuário (usuário + senha)

Este histórico fica salvo só neste navegador — serve para você acompanhar quem já recebeu token e quando vence. Excluir um item daqui não invalida o token (não existe servidor central); se precisar cortar o acesso de alguém antes do prazo, a única forma é trocar a chave secreta (o que invalida todos os tokens já emitidos).
